## 需要双方回答的问题

1. 一个 MPI group 与一个 rank 的 `session_id` 是何关系？每 group 一个三元组如何表达所有成员？
2. 缺少独立三元组类型，是缺少信息、缺少校验，还是仅缺少统一封装？
3. D5 使用全局 `registry_epoch`，同时要求 epoch 更新使所有旧视图失效，是否真能保持无关会话的视图稳定？
4. Worker 级失败锁存的实际范围是什么？1.3 是否明确要求同一 Worker 内部分存活或热迁移？
5. 1.4 的最低安全要求与独立成员事务继续运行的可用性要求，应如何区分？
6. 若会话失效不再推动 registry 换代，如何处理缓存中的旧 ACTIVE 快照和调用方持有的旧引用？
7. 嵌套 MPI 的 UNOBSERVED、manifest 诊断和状态快照，应分别定性为限制、取舍还是缺陷？
8. 哪些结论已有代码或测试证据，哪些仍需需求确认或实验？
